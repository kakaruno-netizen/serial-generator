Serial Generator PWA

구성
- BellSys: 사용 가능
- Kepco: 메뉴만 준비되어 있으며 계산식 추가 필요
- 향후 생성기 추가 가능

아이폰 설치 방법
1. 이 폴더의 파일을 HTTPS 웹서버에 업로드합니다.
2. 아이폰 Safari에서 해당 주소에 접속합니다.
3. 공유 버튼을 누르고 '홈 화면에 추가'를 선택합니다.
4. 최초 접속 후에는 오프라인 실행이 가능합니다.

중요
- iPhone의 파일 앱에서 index.html을 직접 열면 Service Worker/PWA 설치가 동작하지 않습니다.
- PWA 기능은 HTTPS 주소 또는 개발용 localhost에서만 정상 동작합니다.
